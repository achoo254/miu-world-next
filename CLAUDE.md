# CLAUDE.md — Miu World

Thư mục repo: `miu-world-next` (tên hiển thị sản phẩm vẫn là “Miu World”).

Quy tắc hành vi cho agent trong repo này. Lý do và bối cảnh nằm ở `docs/` (bản đồ: `docs/README.md`); nguồn quyết định sản phẩm là Master Plan v3 ở gốc repo.

Giai đoạn hiện tại: Vertical slice MVP đã xong 10 phase; 70 quest học Toán và Tiếng Việt viết bằng lời của mình, tổ chức Môn → Chủ đề → Mục tiêu (`content/learning/topics/`; plan `plans/dattqh/261025-0029-original-learning-content/`), chia trên 8 map rộng (plan `plans/dattqh/261001-2106-more-maps-lesson-regroup/`); chờ người duyệt (report `plans/dattqh/reports/mvp-slice-review-260930.md`, trang `apps/web/review.html`; việc của người: DEVICE-01, giáo viên, designer) — `apps/web` (Vite + React, runtime Three.js ở `src/game`, UI ở `src/ui`), `apps/server` (Express + Drizzle), `packages/{voxel,quest,schema}`. Plan: `plans/dattqh/260929-2141-vertical-slice-mvp/` (trên `main`). Sản phẩm không nhắc sách giáo khoa, lớp, bài hay trang; `pnpm content:check` chặn chữ trùng vân tay SGK và các cụm đó (luật viết: `.claude/rules/quest-content.md`).

## Lệnh

- Chỉ dùng `pnpm` (workspace, `packageManager` khóa trong `package.json`), Node ≥ 22. Không dùng `npm`/`yarn`.
- Dữ liệu ngoài git (chỉ còn thời khóa biểu mặc định) nằm trong iCloud Drive của người phụ trách, danh sách kèm sha256 ở `tools/private/private-files.json`. Máy mới hoặc khi hook đầu phiên báo thiếu: chạy `pnpm private:sync` (macOS và Windows; iCloud ở chỗ khác thì đặt `MIU_ICLOUD_DIR`). Không commit các file đó.
- Gate trước khi báo xong — 5 lệnh, đúng thứ tự CI (`.github/workflows/ci.yml`):
  `pnpm assets:check` → `pnpm content:check` → `pnpm test` → `pnpm typecheck` → `pnpm lint`
  Máy dev 16 GB dùng chung: **không chạy full `pnpm test`, build web hay E2E ở local**. Local chỉ chạy `assets:check`, `content:check`, `typecheck`, `lint` và đúng file test liên quan (`pnpm vitest run <file>`); bộ đầy đủ, build web và E2E chạy trên CI (push `main` hoặc PR): push rồi `gh run watch`, CI xanh mới báo xong.
  (CI còn chạy `pnpm audit --prod --audit-level=high` và Semgrep CE; máy dev không có Docker nên Semgrep kiểm trên CI.)
- Sửa `apps/web/**` thì build web phải xanh: CI chạy `pnpm --filter @miu/web build` (typecheck/test không bắt lỗi build), xem kết quả trên CI thay vì build ở local.
- Một file test: `pnpm vitest run <đường-dẫn-file>`.
- Nội dung học: chủ đề và mục tiêu ở `content/learning/topics/<môn>/`, độ phủ theo mục tiêu `pnpm content:gaps [--missing] [--review]` (`--review` ghi số liệu cho trang review). Kiểm chống chép trong `content:check` cần khóa vân tay (`MIU_FINGERPRINT_KEY` hoặc tệp khóa trong iCloud, tên ở `tools/learning/textbook-fingerprints.ts`; không in): máy không có khóa thì bỏ qua kèm cảnh báo, CI thì báo đỏ; khóa sai định dạng hay không khớp giá trị kiểm `content/learning/textbook-fingerprints.key-check` thì đỏ ở mọi máy. Mục tiêu quest trên map đặt từ `content/world/targets.json` + `looks.json` khi chạy `pnpm world:<map>` (`forest`, `school`, `trung-tam`, `lang-ven-song`, `xom-mai-am`, `cho-phien`, `nong-trai`, `thu-vien`, `lau-dai`, `nui-tuyet`, `dao-bi-an`, `nha-cua-be`); quest mới thì thêm mục trong `targets.json` rồi sinh lại map đó. Sinh lại map nào thì chạy thêm `pnpm world:walk <map>` (lưới chỗ đứng cho bạn máy tự đi, ở `content/world/walk/`; test báo đỏ khi lưới cũ hơn map); số liệu "Bạn máy tự học" trên trang review sinh bằng `pnpm bots:learning` rồi `pnpm assets:manifest`. Mọi model map đặt (đồ vật, người, vật, xe) có một dòng trong `content/world/models.json` (chiều cao, `clip`, `centred`, `traversal`: `walk-through` cho cây, cỏ, hoa, ruộng, thảm; `blocking` cho rào, cửa, lan can, đá lớn; mặc định `auto-step` — bé tự bước 1 khối, tự trèo 2 khối; khối khai `traversal` trong `content/blocks.json`, luật ở `packages/voxel/src/traversal.ts`). Không vật nào mờ đi vì che bé: camera tự tiến lại trước tường, mái. Thêm đồ mới hay đổi cỡ ở đó là áp cho mọi map; map nào cố ý dùng cỡ khác thì khai `sizes` trong generator của map đó; test `tools/world/model-catalog.test.ts` báo model thiếu. Vật pack 3D không có thì thêm prop vào `content/world/emoji-props.json` (ảnh emoji khai trong `tools/assets/sources.json`), chạy `pnpm assets:props` rồi `pnpm assets:manifest`; cùng một nhân vật ở chỗ khác của bài thì khai `character`. Mười hai map chơi được: lõi 800 × 48 × 800 (Nhà của bé `nha-cua-be` lõi 160 × 160) ghi thành vùng 128 × 128 (`regions/r<x>-<z>.bin`) cộng `horizon.bin`, và vùng ngoài quanh lõi tới 5.760 × 5.760 (tọa độ −2.432…3.328) sinh theo seed lúc chơi trong worker (`packages/voxel/src/outland-*.ts`, spec ở `outland` của `entities.json`; không có file); game chỉ giữ các vùng gần bé (`sparse-world.ts`); Trung tâm (`trung-tam`) là map trung tâm có cổng sang mười map và cổng về Nhà của bé, nơi các bạn gặp nhau khi chơi online; Nhà của bé có thời khóa biểu và lịch đồng phục theo hồ sơ (mục tiêu `nha-thoi-khoa-bieu`, `nha-lich-dong-phuc`; API `/api/timetable`, mặc định trống, không đưa dữ liệu thật vào repo); Trường học dựng theo mock ở `designs/truong-hoc/` và `designs/the-gioi/` (`docs/design-cac-map.md`), map mới dựng bằng `tools/world/zone-map.ts`; ảnh so sánh `pnpm assets:preview <map>` (`forest-ch1` cho Khu rừng, `school` cho khung trường). Ảnh toàn cảnh Home: `pnpm world:overview` rồi `pnpm assets:home`. Không commit PDF hay ảnh trang sách.
- Sửa `apps/web/**` hoặc `apps/server/**` thì E2E phải xanh trên CI (job `e2e:ci`); không chạy cả bộ trên máy dev. Chỉ khi cần debug một luồng cụ thể mới chạy local, một project, 1 worker. Lệnh tham khảo: `pnpm --filter @miu/web e2e:smoke` (bộ smoke chạy mỗi lần push/PR: đăng nhập, link mời, Trung tâm và cổng, thưởng chương 1, mua đồ; chặn deploy, khoảng 2 phút) hoặc đúng project đang sửa: `pnpm --filter @miu/web e2e --project setup --project <tên>` (tự chạy server với PGlite trong RAM ở 8787, build web rồi preview ở 4173). CI chạy cùng bộ (`e2e:ci`, job `e2e`, một máy). Các project còn lại (`play`, `quest-mechanics`, `bosses`, `coop`, `worksheets`, test có tag `@nightly`, mọi map với `E2E_ALL_MAPS=1`, `screens`) chạy hằng đêm ở job `e2e-nightly` (`e2e:nightly`, 02:00 giờ Việt Nam hoặc `workflow_dispatch`); hành vi của chúng được unit/API test khóa trên mỗi lần push. Kiểm theo nội dung viết ở Node, không thêm E2E (audit mục tiêu quest `pnpm world:quest-targets` nằm trong `content:check`). Sau build web, `pnpm security:dist` kiểm không có đáp án quest trong bundle.
- Chạy dev: `pnpm dev` chạy cả hai và tự nạp client dev `miu-web-dev` của auth-next (entry `auth.hoandat.com` / `miu-world dev`) từ `access-tokens.json` trong iCloud (không in, không ghi file); từng phần: `pnpm --filter @miu/server dev` (API cổng 8787, chỉ loopback, PGlite ở `.data/pglite`) và `pnpm --filter @miu/web dev` (cổng 5173, proxy `/api` → 8787). Trang game `/play` cần đăng nhập phụ huynh và chọn hồ sơ; trang duyệt `/review.html`, trang render công cụ `/preview.html`.
- Ngân sách thời gian test: một test chạy quá 30 s phải khai `test.setTimeout` kèm lý do; cả lượt `e2e:ci` trên CI không quá 180 s (reporter đánh đỏ khi vượt). Máy dev chỉ chạy 1 worker, không chạy song song nhiều bộ test. Kiểm tra tăng theo lượng nội dung đặt ở Node; E2E chỉ giữ luồng chính. Chi tiết: `docs/code-standards.md`.
- KHÔNG chạy project `perf` ở máy dev trừ khi được yêu cầu đo hiệu năng: mất tới ~30 phút và ghi đè `assets/generated/review/perf.json` (`perf` và `budget` cần GPU thật nên chỉ chạy tay, không chạy trên CI).

## Không được làm

- Không sửa tay `assets/manifest.json` hay `assets/LICENSES.md` — sinh lại bằng `pnpm assets:manifest`. Gate so manifest với bản build mới và sẽ đỏ.
- Không thả file vào `assets/` ngoài quy trình pack/generator (xem `.claude/rules/assets-pipeline.md`). Mọi file phải có trong manifest, license trong allowlist.
- Không đặt thư mục tên `vendor` hay `build` dưới `assets/` — hook của môi trường AI chặn các từ đó; dùng `assets/packs/` và `assets/generated/`.
- Không dùng tên, texture, asset của Minecraft. Không nhận license CC-BY, CC-BY-SA, NC. Không tự vẽ tay, không dùng AI tạo ảnh trả phí, không dùng model AI giấy phép non-commercial.
- Cái gì vẽ được bằng AI thì vẽ bằng AI (người sở hữu chốt 29/10/2026): ảnh, nền, đảo Home, nền khu vực, icon, minh họa UI, giọng đọc… Vẽ bằng skill `inet-artgen` (model cho phép thương mại, danh sách trong skill), chỉ trên GPU của PC Windows của chủ sở hữu: phiên chạy trên PC vẽ trực tiếp; phiên trên Mac gửi yêu cầu sang PC qua tailnet khi PC online (`artgen.py --health` báo ok); PC offline thì ghi việc vẽ vào plan là pending, chờ PC online, không vẽ thay bằng cách khác. License `LicenseRef-hoandat-all-rights-reserved`, "AI-generated for the hoandat ecosystem; owned by hoandat, all rights reserved (not CC0)"; gate chỉ nhận license đó cho file khớp `brandArt.globs` trong `tools/assets/sources.json`, nên nhóm mới thì thêm glob và ghi `source` (AI, model) trong `tools/assets/generated.json`. Ảnh gốc giữ ở `designs/<nhóm>/`, script dẫn xuất ra `assets/generated/<nhóm>/` (ảnh WebP, xác định byte). Chữ trên ảnh không để model viết: tên, nút, nhãn là HTML. Ví dụ đang dùng: logo và icon app (ảnh gốc `designs/brand/miu-logo-master-1024.png`, `pnpm assets:logo` suy ra mọi cỡ, cả thẻ chia sẻ có logo; ảnh gốc này vẽ bằng OpenAI gpt-image ngày 26/10/2026, trước luật này); ảnh menu 2D (`designs/ui-art/`: đảo Home/Bản đồ vẽ lại từ `generated/home/world.png`, nền 12 khu vực từ `generated/regions/<id>.png` bằng `klein-edit --ref` để giữ bố cục, `pnpm assets:ui-art` ra `generated/ui-art/*.webp`); giọng đọc lời nhân vật `assets/generated/voice/*.m4a`, đọc một lần bằng VieNeu-TTS v3 Turbo (Apache-2.0, chỉ giọng có sẵn, không nhân bản giọng người thật) bằng `pnpm assets:voice`; vai giọng ở `content/voice/cast.json`, ai đọc câu nào ở `content/voice/recorded.json`. Câu có `{name}` và câu chưa có file vẫn đọc bằng giọng của máy. Pack CC0/MIT/OFL và asset sinh bằng code (khối voxel, nhân vật ghép bộ phận, map) vẫn dùng như cũ.

- Không tính thưởng, XP, mở khóa ở client — server là nguồn sự thật (áp dụng ngay khi có backend).
- Không đưa secret hay dữ liệu thật của trẻ vào prompt, code, fixture hoặc commit.

Không commit, push hay dán vào issue/PR bất kỳ credential, token, API key, mật khẩu, private key, tệp env thật, bản dump database, dữ liệu cá nhân, cũng như IP public, cổng SSH hay user của máy chủ, **trừ khi người dùng cho phép rõ ràng cho đúng lần đó**. ## Dễ vấp

- Trên Windows chưa bật Developer Mode, test symlink trong `tools/assets/check-assets.test.ts` tự skip (không tạo được symlink); CI (Ubuntu) vẫn chạy. Skip này không có nghĩa là gate symlink đã được kiểm trên máy local.
- Dữ liệu dev (tài khoản, hồ sơ, tiến độ) nằm ở `.data/pglite` của **từng** worktree: worktree khác có database riêng, không dùng chung với `main`. Không xóa `.data/pglite`; lần duyệt cần dữ liệu giả thì chạy server với `PGLITE_DIR=.data/pglite-review` và chỉ xóa thư mục đó. E2E dùng database trong RAM (`PGLITE_DIR=memory`), tắt là mất. Lúc khởi động server in dòng `database: …` cho biết đang mở database nào và có phải vừa tạo rỗng không.
- `render-preview.ts` và perf test tự sinh lại manifest khi chạy xong; nếu tự sửa file trong `assets/generated/` bằng cách khác thì phải chạy `pnpm assets:manifest`.
- Cổng cố định: web dev 5173, preview/E2E 4173 (Vite `--strictPort`); server 8787 (cổng cố định trong config, lỗi nếu bận); render-preview 5199. Báo cổng bận thì tìm và tắt server cũ, không đổi cổng. Quy tắc này chỉ áp cho máy dev: trên máy chủ dùng chung, tiến trình giữ cổng có thể thuộc dự án khác, nên không được tắt (xem `docs/deployment-guide.md`).
- Server từ chối POST không có `Origin` trong danh sách cho phép (chống CSRF). Mặc định chỉ có localhost/127.0.0.1 ở 5173/4173 (và 5174/4174 cũ); duyệt qua LAN thì chạy server với `ALLOWED_ORIGINS=http://<ip-LAN>:<cổng>` (danh sách phân tách bằng dấu phẩy) và mở web với `--host`.
- Đăng nhập phụ huynh qua dịch vụ đăng nhập dùng chung auth-next (`https://auth.hoandat.com`, OpenID Connect; từ 23/10/2026 thay Google OAuth trực tiếp): server cần `OIDC_WEB_CLIENT_SECRET` và `OIDC_REDIRECT_URI` (khớp đúng redirect của client ở IdP; dev: client `miu-web-dev`, `http://localhost:5173/api/auth/callback`, thêm `OIDC_WEB_CLIENT_ID=miu-web-dev`); `OIDC_ISSUER` mặc định theo `brand.config.json`, http chỉ cho IdP giả trên loopback ngoài production (E2E). App iPhone/Android đăng nhập bằng client `miu-mobile` trong trình duyệt hệ thống rồi đổi code ở `/api/auth/native/exchange` lấy token Bearer. Đặt trong file env ngoài repo và chạy `pnpm --filter @miu/server exec tsx --env-file=<file> src/server.ts`; không in giá trị. Chi tiết: `docs/deployment-guide.md` §5.1. Đăng nhập mật khẩu chỉ bật khi đặt `PASSWORD_LOGIN=1` (E2E đặt; bản review không đặt), bị từ chối ở production. Duyệt qua tunnel: `tunelo http 4173:miu` → `https://miu.tunnel.hoandat.com`, chạy preview với `MIU_PUBLIC_HOSTS=miu.tunnel.hoandat.com` và server với `ALLOWED_ORIGINS` gồm origin đó.
- `jev-decide.py` cần `TYPESAFE_API_KEY` hoặc `TYPESAFE_TOKEN_FILE`. `TYPESAFE_TOKEN_FILE` trỏ tới file token `access-tokens.json` trong iCloud của người phụ trách (đường dẫn trong `docs/STAG-DEV-README.md` §3, cùng thư mục với các file credential khác); script lấy mục `api.typesafe.ai` và không in khóa. Không có file đó thì dừng, đừng tự tìm key ở nơi khác.
